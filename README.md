# GerenciadorProdutos
Este projeto tem como objetivo criar um software para o gerenciamento de produtos de um comércio pequeno.

## Objetivo
O programa inicia na classe program onde será executada a função menu com 4 funções: Listar, Adicionar, Remover e Buscar, também é onde está o main, na classe seguinte há o gerenciamento que possui a lista de produtos e todas as funções do programa. 
O produto tem uma classe bebida, comida e limpeza e as interfaces IVerificarAlcool e IVerificarDisponibilidade.
